量子もつれインタラクティブ解説

スピン1/2粒子のシングレット状態 |Ψ⁻⟩ と ベル（CHSH）試験 — 量子力学の予測に基づくシミュレーション

1. 量子もつれとは

量子もつれとは、複合系全体の量子状態が、各部分系の状態の積として表せない性質です。2つのスピン1/2粒子（電子のペアや、偏光もつれ光子など）の最も単純な例がシングレット状態です。

|Ψ⁻⟩ = ( |↑⟩A|↓⟩B − |↓⟩A|↑⟩B ) / √2

この状態は全角運動量がゼロで、どの方向から見ても同じ形（回転対称）です。個別の粒子はどの軸に沿っても ↑/↓ が 1/2 ずつの完全な乱数で、決まった方向を持っていません。しかし「Aの測定結果とBの測定結果が同じ軸なら必ず反対」という関係は、ペア全体で厳密に成立します。

シングレット状態の予測（結果を +1 / −1 と数える）

  • 同じ軸で測定 → 必ず反対（完全な逆相関、E = −1）
  • 軸のなす角が θ → 相関 E(θ) = −cos θ （E = 二つの結果の積の平均）
  • 片方だけの結果は常に 50/50 の乱数であり、コントロール不能
  • → 超光速通信は原理的に不可能（非シグナル性）
  • この相関はいかなる局所的隠れた変数理論でも説明できない（ベルの定理）

ベル（CHSH）不等式

Alice と Bob がそれぞれ2種類の軸から選び測定するとき、もし結果が粒子が運んできた局所的な「事前決定」で決まるなら、

S = E(a,b) + E(a,b′) + E(a′,b) − E(a′,b′),   |S| ≤ 2

が必ず成り立ちます。一方、シングレット状態の量子力学的予測は |S| の最大 2√2 ≈ 2.83（ツァイレソン上限＝量子力学が許す最大の値）に達します。実験は量子力学側を支持しています。

2. 歴史

  • 1935 アインシュタイン＝ポドルスキー＝ローゼン（EPR）のパラドックス。量子力学は不完全だと主張。シュレーディンガーがこの現象を「もつれ（Verschränkung）」と命名。アインシュタインはこれを「不気味な遠隔作用」と呼んだ。
  • 1964 ジョン・ベルがベルの不等式を導出。もつれの議論が哲学問題から実験で検証可能な科学問題に。
  • 1969 CHSH 不等式（クラウザー＝ホーン＝シモーニ＝ホルト）が提案され、実験に向いた形になった。
  • 1972 フリードマン＆クラウザーが、もつれ光子の偏光でベル不等式違反を初めて実験的に確認。
  • 1982 アスペらが測定軸を高速に切り替える実験で、局所性仮定をさらに厳密にチェックし違反を確認。
  • 2015– 検出効率と局所性の「抜け穴（loophole）」を同時に閉じたベル試験が実現。
  • 2022 ノーベル物理学賞：アラン・アスペ、ジョン・クラウザー、アントン・ツァイリンガー。「もつれた光子を用い、ベル不等式の違反を実証し、量子情報科学の先駆となった業績」による。

5. なぜ超光速通信できないのか（非シグナル性）

Bob がどの軸を選ぶかによって A と B の相関は変化しますが、Alice 一人ではそれを知る術がありません。なぜなら、Bob の軸の選び方にかかわらず、Alice 自身の結果は常に ↑/↓ 1/2ずつの乱数だからです（上の実験1の「Alice の結果分布」を Bob の軸を変えながら見てください — 常に 50/50 のままで変化しません）。

もつれ粒子どうしの相関を確認するには、双方が各自の結果を光速以下の通常の通信路で照合するしかありません。測定が「即座にもう片方の状態を決めてしまう」ように見えても、情報が届く速度は光速度を超えません。この性質は量子力学と相対論が両立できる理由であり、「非シグナル性（no-signaling）」と呼ばれる定理として証明されています。

6. このシミュレーションについて・参考

  • 本プログラムは量子力学の予測をモンテカルロ法でサンプリングしたシミュレーションです。各ペアの結果は Born ルールの確率分布 P(反対) = cos²(θ/2)、P(同じ) = sin²(θ/2) から生成しています。「相関が物理的にどう実現されるか」の機構そのもののモデルではありません。
  • 「局所隠れた変数」モデルは、粒子対の生成時に共通の隠れた変数 λ を渡し、あらゆる軸に対する測定結果を事前決定した最も単純な決定論的モデル（A = sign cos(α−λ), B = −sign cos(β−λ)）です。ベルの定理はすべての局所隠れた変数理論に |S| ≤ 2 を強いるので、この1つのモデルが 2√2 に届かないことは代表的です。
  • 実際の光子実験では偏光を測定します。偏光は π 周期なので相関は E = −cos 2θ になり、標準的な角度は a = 0°, a′ = 45°, b = 22.5°, b′ = 67.5° です。スピン1/2の場合は本ページのように E = −cos θ です。
  • 検出器は理想（検出効率 100%、フェアサンプリング）としています。実際の実験では検出の抜け穴・局所性の抜け穴などに注意が必要です。
  • 「相関」は古典的な確率理論の相関と同じものではなく、「適切な実験によって実際の相関を生成できる潜在的な相関」と理解すべきです（ベルマンの靴下とよく比較されますが、もつれはそれと根本的に異なります）。
